2. **transform_data_task**
```python

    task_id='transform_data',

```
This task is responsible for transforming the loaded data using the `transform_data` function.

3. **load_and_transform_data_task**
```python
load_and_transform_data_task = ChainOperator(
    tasks=[load_data_task, transform_data_task]
)
```
This task is a combination of the above two tasks and runs them sequentially.

**DAG Definition:**
```python
from datetime import datetime, timedelta
from airflow import DAG

default_args = {
    'owner': 'airflow',
    'depends_on_past': False,
    'start_date': datetime(2023, 1, 1),
    'retries': 1,
    'retry_delay': timedelta(minutes=5),
}

dag = DAG(
    'booking_record_dag',
    default_args=default_args,
    schedule_interval='@daily'
)

load_and_transform_data_task >> dag
```
This defines the Airflow DAG with three tasks: `load_data`, `transform_data`, and `load_and_transform_data`. The DAG runs daily at midnight.
