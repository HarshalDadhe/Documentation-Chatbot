**DAG Tasks:**

1. **Load Data:**
    * Task Name: Load Booking Data
    * Description: Loads data from an external source (e.g., CSV file) into the `booking_record` table.
    * Trigger: Every day at 8am (triggered by Airflow's scheduler)
2. **Transform Data:**
    * Task Name: Transform Booking Records
    * Description: Transforms loaded data into a suitable format for storage in the `booking_record` table.
    * Trigger: After successful completion of Load Data task

** Dag Flow:**

1. The DAG is triggered every day at 8am.
2. When triggered, the Load Data task executes and loads data from an external source (e.g., CSV file) into the `booking_record` table.
3. Upon successful completion of the Load Data task, the Transform Data task executes and transforms the loaded data into a suitable format for storage in the `booking_record` table.

**Example Use Case:**

This DAG can be used to manage booking records for a hotel or resort. It can be triggered daily to load new booking data, transform it into a suitable format, and store it in the database. This ensures that the booking record table is always up-to-date and accurate.

**Troubleshooting Tips:**

* Check the Airflow logs to identify any errors or issues with the Load Data task.
* Verify that the external source (e.g., CSV file) exists and contains valid data.
* Review the Transform Data function to ensure it meets the requirements of the `booking_record` table.
